# Obaapa Essen — Restaurant Website

Live site: https://kingjudecole.github.io/ObaapaEssen/

Local & continental restaurant at Dansoman Junction, Accra.
Single-file site (index.html) — online ordering via WhatsApp, Google review funnel, live opening hours.

## Editing
- Menu items & prices: edit the MENU array at the top of the <script> in index.html
- Opening hours: the LIVE HOURS block in the same script
- Google review link: search for 'google.com/maps/search' and replace with your Google Business review link
